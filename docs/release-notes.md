# 白日梦 Daydream 1.17.3

YouTube 双语字幕与网页文字翻译扩展，MIT 许可，免费提供源码和安装包。

- `Alt+A` 开关 YouTube 字幕翻译，`Alt+W` 独立开关网页文字翻译。
- 默认使用 Chrome 本地翻译；也可选择用户自行配置的腾讯云或豆包服务。
- 字幕失败有限重试、过期隐藏、缓存恢复、请求优先级及进行中请求共享。
- 云翻译使用用户自己的凭据，服务商可能收费；本项目不提供共享密钥。

**[从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/dnpdkhjoephecffekgldnaooolnffeih)**，无需开启开发者模式。

也可下载 `daydream-1.17.3.zip`，解压后在 `chrome://extensions` 开启开发者模式，加载包含 `manifest.json` 的目录。`daydream-1.17.3-source.zip` 为完整源码。需要 Chrome 138 或更新版本，本地翻译功能还取决于浏览器与设备支持；首次使用或更新后刷新网页。

本次公开整理未修改翻译逻辑，仅增加 MIT 许可、署名、公开说明与可移植的开发脚本。模拟接口和独立浏览器检查不代表真实 YouTube Shorts 或真实云服务均已验收。本次仅发布 GitHub，未操作 Chrome 商店。
